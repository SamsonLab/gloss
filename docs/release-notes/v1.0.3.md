# Gloss 1.0.3

Gloss 1.0.3 adds a choice between lightweight and bundled-Codex distributions.

## Optional bundled Codex distribution

- Keeps the default Homebrew and GitHub Release download lightweight and without Codex.
- Adds the mutually exclusive `sunchj/tap/gloss-with-codex` Cask for users who want the Codex app-server runtime bundled with Gloss.
- Publishes arm64 and x86_64 `-with-codex` archives alongside the default release archives.
- Verifies checksums, architecture, signatures, and the expected presence or absence of the Codex helper for both variants.
- Runs Homebrew installation smoke tests for both variants on Apple silicon and Intel runners.

Gloss 1.0.3 requires macOS 14 or newer.
